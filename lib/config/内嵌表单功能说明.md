# 内嵌表单功能实现说明

## 功能概述
已成功实现内嵌式充值提现表单功能，表单直接显示在红色区域内，而不是通过弹窗。

## 实现的功能

### 1. 状态管理
- 在 `UserProfileController` 中添加了 `walletContentIndex` 状态管理
- 0 = 余额显示
- 1 = 充值表单
- 2 = 提现表单

### 2. 表单组件
- `DepositForm` - 充值表单组件
- `WithdrawForm` - 提现表单组件
- 两个表单都支持关闭按钮返回余额显示

### 3. 界面更新
- `WalletView` 更新为使用内嵌表单
- 红色区域动态显示不同内容
- 点击充值/提现按钮直接切换表单

## 文件结构

```
lib/app/modules/userProfile/
├── controllers/
│   └── user_profile_controller.dart  # 添加了钱包内容状态管理
├── views/
│   └── wallet_view.dart              # 更新为内嵌表单显示
└── widgets/
    ├── deposit_form.dart             # 充值表单组件
    └── withdraw_form.dart            # 提现表单组件
```

## 使用方法

1. **显示余额**: 默认状态，显示钱包管理界面
2. **充值操作**: 点击"充值"按钮，红色区域显示充值表单
3. **提现操作**: 点击"提现"按钮，红色区域显示提现表单
4. **返回余额**: 点击表单中的"取消"或"关闭"按钮返回余额显示

## 技术特性

- **响应式设计**: 使用 `Obx` 监听状态变化
- **表单验证**: 完整的输入验证和错误提示
- **加载状态**: 提交时显示加载指示器
- **API集成**: 与现有的支付服务完全集成
- **用户体验**: 流畅的界面切换，无需弹窗

## 状态切换流程

1. **初始状态**: 显示钱包管理图标和提示文字
2. **点击充值**: 红色区域切换为充值表单
3. **点击提现**: 红色区域切换为提现表单
4. **操作完成**: 自动返回余额显示状态
